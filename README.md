# Customer Churn Prediction

End-to-end telecom customer churn prediction using Python and machine learning.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter.

## Workflow
Data loading → cleaning → EDA → encoding → train/test split → Logistic Regression → Random Forest → evaluation → feature importance → prediction.

## Dataset
`WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Run
`pip install pandas numpy matplotlib seaborn scikit-learn jupyter`

Then open `Customer_Churn_Prediction.py` in Jupyter/VS Code and run it.

Use this as a reference and customize the explanations, analysis, and conclusions before submitting.
